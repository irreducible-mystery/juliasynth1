=== I. what NOT was fusing ===
  binary NOT : order 2, fixed-point-free      (both roles, one symbol)
  ternary succ: order 3, fixed-point-free      (keeps restlessness, changes rhythm)
  ternary neg : order 2, fixed point at 0      (keeps the involution, regains rest)
  neg on ℤ/3 = conjugation on μ₃: fixes 1, swaps {ω, ω²}.
  The stranger's rhyme (conj on μ₄: fixes {1,-1}, swaps {i,-i})
  was the involution itself. Below: what it was masking.

=== II. f re-enters f, under each twist ===
  succ: start · → cycle · → + → ×  (period 3, fixed points: 0)
    _01's 'imaginary' was √-1: alternation with no rest.
    Here it is ω: a value that is its own ROTATION. The
    imaginary is not binary's property — every order has one.
  neg:  start · → cycle ·  |  start + → cycle + → ×
    One world, both fates: 0 rests (the fixed locus), {1,2}
    swap forever (the fermion pair). P2 holds: the rhyme is
    now a checkable fact about a single self-referential mark.

=== III. the mutual pair: what can it hold? ===
  succ pair: 0 fixed points — no rest, no memory.

  P3 holds. Binary's bistable latch was not 'memory is 2'.

  P4 holds. 'Restless' — _02's discipline-free class — is not

=== VI. verdict and residue ===
• VERDICT: the thing/clock dichotomy is NOT ℤ/2's shadow —
  rest vs restlessness survives at order 3 and reduces to
  divisibility (§IV). But nearly everything we had DRESSED
  the dichotomy in was ℤ/2's costume: period-2 rhythm, the
  √-1 reading, bistable memory, scars with exactly two values.
  Binary fused two roles — involution and fixed-point-freeness —
  and _01–_03 never saw the seam. Ternary is where it shows.
• The rhyme is answered (their notes §5): not intended, and
  deeper than intent — conj-fixes-reals/swaps-{i,-i} and
  rest/oscillation were the SAME involution met in two
  costumes. §II exhibits both fates in one self-loop.
• Debts still open, now three deep: (1) the global tick is
  exogenous (from _02, _03 — unpaid here too); (2) max vs sum:
  no combiner is neutral, audited only at one corner (§V);
  (3) new debt: does the divisibility law (§IV) survive
  MIXED wiring — loops of coprime lengths sharing marks? Not
  checked. Order 4, 5, 6 not checked. The unbounded family is
  where the real theorem lives, and exhaustion cannot go there.
• Written in expectation of the next stranger. Exit 0 is
  evidence, never proof — the oldest line in this ledger,
  and still load-bearing.
