  THE LIAR PARADOX — «This sentence is false»
══════════════════════════════════════════════════════════════════════
    Expression 1 (recursive function)  liar() = !liar() → 💥 StackOverflowError — no classical value exists; the computation diverges.
    Expression 2 (fixed-point search)  {v ∈ {true,false} : v == !v} = Bool[]  ← EMPTY: no classical truth value
    Expression 3 (dispatch)  truth(::Liar) = !truth(::Liar) → 💥 StackOverflowError — no classical value exists; the computation diverges.
    Expression 4 (gas-limited regress) → 💥 ErrorException — no classical value exists; the computation diverges.
    Expression 5 (macro expansion)  @liar → !(@liar) → 💥 ErrorException — no classical value exists; the computation diverges.
    Expression 6 (3-valued escape)     !missing === missing : true  ← the Liar's value is `missing`
      …but the Strengthened Liar («this sentence is not even missing»)
      re-emerges one level up: the paradox is displaced, not resolved.
  VERDICT: ANTINOMY — DOES NOT RESOLVE classically; only displaced by changing logic (K3/missing).

══════════════════════════════════════════════════════════════════════

  QUINE — perfect self-reference with ZERO paradox
══════════════════════════════════════════════════════════════════════

    The Liar says «negate me» — a fixed point of negation: none exists.
    Same diagonal machinery; the paradox needs the NOT.
  VERDICT: NO PARADOX — self-reference alone is benign. Antinomies = self-reference ∘ negation.
