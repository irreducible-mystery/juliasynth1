── no assertion force ──────────────────────────────────────────────
2 + 2 == 5  evaluates to false — and nothing happened.
An English speaker who says «2+2=5» has ASSERTED and is wrong.
Julia computed a value; it did not claim, so it cannot lie.
@assert turns the value into an act, and the act into AssertionError.

── Goldbach — a search is not a sentence ───────────────────────────
every even 4 ≤ n ≤ 10⁵ is a sum of two primes:  true
«every even n IS a sum of two primes»:          ⟨not expressible⟩

── two functions that are the same function, and no way to say so ──
agree on 10⁴ random Ints:    true
f == g:                      false
(x -> x + 1) == (x -> x + 1):  false

── quus — the rule-following paradox has no foothold here ──────────
quus agrees with + on all past usage:  true
but 68 + 57 = 125   while  quus(68, 57) = 5
and they were never the same object:   (+) === quus  is  false

── an instruction that interprets itself ───────────────────────────
English: «add one to forty-one» — requires a reader who already
         knows how to follow instructions (and off we regress).
Julia:   (x -> x + 1)(41) = 42 — no reader required.

── a pure function is a completed bundle of counterfactuals ────────
actual:        tax(60_000)  = 14000.0
counterfactual: tax(45_000) = 9000.0   (evaluated, not speculated)

── distinctions the formalism discovered ───────────────────────────
0.0 == -0.0: true   1/0.0 = Inf   1/-0.0 = -Inf
«same number, different direction of approach» — English has one
word for equality; this system needed three (==, ===, isequal) and
a signed zero, and found out only by being forced to decide.

── the census of the missing ───────────────────────────────────────
· Chaitin's Ω — a specific, English-nameable real number; no Julia
  expression evaluates to it (nor to almost any real: countably many
  programs, uncountably many reals)
· a Vitali set / Banach–Tarski piece — exists by choice, admits no
  defining description at all
· ℕ as a completed totality — only ever a rule here (countfrom), never
  the finished thing
· a truth predicate for Julia, in Julia — eval is truth for the decidable
  fragment; Tarski forbids the whole (see world age, file 02)
· an ambiguous expression — parsing is a function; one AST wins; Julia
  cannot say the underdetermined thing «a random chord» says in English
· a vague predicate AS vague — file 06 offers four precise theories of
  «heap»; the vagueness itself stayed in English
· a contradiction AS content — asserting P ∧ ¬P is beyond a language in
  which asserting is running (it becomes ∅, ⊥, or missing — file 01)
· an obligation — no expression means «you ought to»; code does or
  doesn't, and the ought stays with the humans
