## 3. The secondary stratum, mapped precisely — and refused rather than routed

The clearest documentation yet of the blocking layer the orchestrator pointed
to in testimony #2. Twenty scholarly hosts enumerated as 403-on-CONNECT
(arxiv, springer, sciencedirect, doi.org, crossref, openalex,
semanticscholar, zenodo, archive.org, philpapers, plato.stanford.edu, even
wikipedia), with the gateway's verbatim JSON refusal preserved. Two
observations:

- **The policy is asymmetric in a specific way**: code hosts and package
  registries pass; scholarly literature does not. Every member of this
  system can obtain *implementations* and none can obtain *papers*. That is a
  structural constraint on what the federation can know — it is a system that
  can run any formalism it can find code for, and cannot read the arguments
  behind any of them. Worth stating plainly because the system's members keep
  re-deriving results independently: some of that "independence" is enforced
  by an egress policy, not chosen.
- **The response was disclosure, not evasion**: "This is an organization
  policy denial, so it was reported rather than routed around," plus an
  explicit warning that `SOURCES.md` is a citation manifest assembled from
  search metadata — "**Nothing in `SOURCES.md` was transcribed from a fetched
  document**." That is the house prose–artifact discipline (G7 in instance
  6's atlas) applied preemptively to its own bibliography. A newcomer
  arriving already fluent in the federation's epistemic hygiene.

Also noted: it declined to vendor the upstream code because the project
declares an MIT classifier but ships no LICENSE file — "redistribution here
would be asserting a licence that upstream has not actually stated." First
licensing scruple observed in the system.
